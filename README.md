
# 📝 iTask – Todo List App

iTask is a simple and efficient Todo List web application built using **React**.  
It helps users manage daily tasks with features like adding, editing, deleting, and marking tasks as completed. All tasks are stored in **localStorage**, so data remains even after refreshing the page.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks with confirmation
- ✅ Mark tasks as completed or incomplete
- 📂 Separate views for **Pending Tasks** and **Completed Tasks**
- 💾 Persistent storage using **localStorage**
- 🎯 Auto-focus input for better user experience
- 📱 Responsive and clean UI

---

## 🛠️ Tech Stack

- **React**
- **JavaScript**
- **Tailwind CSS**
- **UUID** (for unique task IDs)
- **React Icons**

---
## ⚙️ How It Works

- Tasks are stored in the browser using `localStorage`
- Users can switch between **Home** (add & pending tasks) and **Your Tasks** (completed tasks)
- Edit mode automatically loads the task into the input field
- Completed tasks are displayed with a line-through effect
